# React Theme Switcher

![React](https://img.shields.io/badge/React-Frontend-blue)
![Tailwind CSS](https://img.shields.io/badge/TailwindCSS-Styling-06B6D4)

## Overview

A React application that demonstrates theme switching using Context API and global state management. Users can toggle between light and dark themes with instant UI updates.

## Features

- Light/Dark theme toggle
- Context API implementation
- Global state management
- Dynamic UI updates
- Reusable components

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Vite
